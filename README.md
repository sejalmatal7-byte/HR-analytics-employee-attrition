# HR Analytics - Predict Employee Attrition

## 📌 Project Overview
This project predicts employee attrition using machine learning and analyzes the key factors responsible for employees leaving the organization. It also provides interactive visualizations and business recommendations to reduce attrition.

## 🎯 Objective
- Analyze HR data
- Predict employee attrition
- Identify important factors affecting attrition
- Help organizations improve employee retention

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Power BI (Optional)
- Jupyter Notebook

## 📂 Dataset
Dataset Source:
IBM HR Analytics Employee Attrition Dataset (Kaggle)

## 📊 Project Workflow
1. Import dataset
2. Data cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Data Visualization
6. Data Preprocessing
7. Model Building (Logistic Regression / Decision Tree)
8. Model Evaluation
9. Feature Importance Analysis
10. Business Recommendations

## 💡 Key Insights
- Overtime employees have higher attrition.
- Lower job satisfaction increases attrition.
- Employees with lower income are more likely to leave.
- Younger employees show higher attrition rates.
